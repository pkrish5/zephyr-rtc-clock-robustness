# Pinned upstream RTC test sources

This directory copies the Zephyr `tests/drivers/rtc/rtc_api` test application
from commit `3568e1b6d5cdd51a6b964a2a1d6d29200fea2056`. The study selected its
alarm callback, alarm pending, and calendar counting cases. The accompanying
`Apache-2.0.txt` contains the upstream license. The full Zephyr checkout is
needed to build the tests and is not duplicated here.
