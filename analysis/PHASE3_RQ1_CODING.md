# RQ1 source-review rubric

Registered 2026-09-29 before completing the exhaustive RQ1 coding. Early Phase 3 RTC outcomes and the earlier Phase 1 RTC flip were already visible to this reviewer, so this is **not blinded** source coding; independent blinded review remains necessary. Unit: each frozen agent `test.c` among the original 55 and each of the 11 matched upstream ztest **selected cases**. The separate RTC context supplement is an additional condition and is summarized separately, not added to the primary agent denominator. Review the source and scanner candidates together; the scanner is not a classifier. Preserve build and nominal outcomes as separate fields. A noncompiling suite can still contain a source-level assumption, but it cannot have an observed pass-to-fail flip.

Mark `unjustified` only when a test's pass/fail assertion depends on a timing or ordering premise that the supplied specification, synchronous API semantics, or documented hardware bound does not support. Categories are fixed waits used as proof of event arrival or absence, finite deadlines shorter than a documented legal arrival interval, immediate checks that assume asynchronous callbacks are simultaneous, and shared-state reads without a defined synchronization/visibility relation. A sleep that **creates the behavior under test** or a `K_NO_WAIT` check following a synchronous `irq_offload()` return is not automatically unjustified. A generous timeout without a documented worst-case ISR/scheduling latency can be coded `uncertain` unless a reachable legal schedule proves it too short; do not count absence of a formal latency guarantee alone as a defect. `unknown` preserves unclear API or compiler ordering, unverified scheduling margins, and incomplete specifications. `none_found` means the selected source was reviewed and no unsupported timing premise was found; it is not a proof of timing correctness.

For each unit record source hash, status (`unjustified`, `none_found`, `unknown`), category, line-level evidence, and reviewer. If multiple issues exist, record each one and count the unit once in an “any unjustified” numerator. Report all three statuses and, if presenting a proportion, a 95% Wilson interval for the `unjustified` count over the full registered unit denominator, with `unknown` displayed separately. These are one-reviewer exploratory estimates until a second reviewer independently codes and disagreements are reconciled. Do not use Phase 3 flips as a substitute for source-level RQ1 coding; flip classification is a separate analysis.
