Use a saved pseudorandom order that interleaves model and context conditions within each generation round. The generation unit is one fresh CLI call; store its exact prompt, raw JSON events, stderr, response, source, hashes, timestamps, reported model/version if any, token usage if any, and every failed/retry attempt. Do not replace a harness-error nominal result with a diagnostic pass.

Predeclared contrasts and analysis units are in [`paper/DESIGN.md`](../../paper/DESIGN.md): all three pairwise models within condition; range present versus absent within model; model × context interaction; and each model/condition versus its matched upstream case.
